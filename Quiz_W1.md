# Quiz_W1

## Week 1 Quiz – Questions & Correct Answers

| No. | Question | Correct Answer |
|:---:|----------|----------------|
| 1 | Cloud computing refers to: | Delivering computing resources over the Internet |
| 2 | Which is NOT an essential characteristic of cloud computing? | Manual Provisioning |
| 3 | Which characteristic allows cloud resources to automatically grow or shrink? | Rapid Elasticity |
| 4 | Which deployment model provides the MOST control? | Private Cloud |
| 5 | Which deployment model combines private and public cloud? | Hybrid Cloud |
| 6 | Which service model provides virtual machines? | IaaS |
| 7 | Google Docs is an example of: | SaaS |
| 8 | Which service model requires customers to manage the operating system? | IaaS |
| 9 | Docker is mainly used to: | Run containers |
| 10 | The smallest deployable unit in Kubernetes is: | Pod |
| 11 | A Kubernetes cluster consists of: | Multiple nodes |
| 12 | A node is: | A worker machine |
| 13 | Which command lists Kubernetes nodes? | `kubectl get nodes` |
| 14 | Which tool creates a local Kubernetes cluster? | `kind` |
| 15 | LocalStack is used because it: | Simulates AWS services locally |
| 16 | Which endpoint is commonly used with LocalStack? | `http://localhost:4566` |
| 17 | Which AWS CLI command verifies the current identity? | `aws sts get-caller-identity` |
| 18 | Which AWS identity has unlimited privileges? | Root User |
| 19 | Which IAM component contains permissions? | IAM Policy |
| 20 | A collection of IAM users is called: | IAM Group |
| 21 | Which IAM identity is normally used as a temporary identity? | IAM Role |
| 22 | Which security principle gives users only the permissions required to perform their tasks? | Principle of Least Privilege |
| 23 | For easier permission management, policies should preferably be attached to: | IAM Groups |
| 24 | Which AWS-managed policy provides full administrative access? | `AdministratorAccess` |
| 25 | Access keys are mainly used for: | Programmatic access |
| 26 | If an access key is compromised, what should be done first? | Deactivate or rotate the key |
| 27 | Which account should never have access keys created for routine use? | Root User |
| 28 | What does ARN stand for? | Amazon Resource Name |
| 29 | In the ARN `arn:aws:s3:::my-bucket`, which component represents the AWS service? | `s3` |
| 30 | Which ARN component identifies the AWS account that owns the resource? | Account ID |

> **Note:** This document contains the correct answers for the Week 1 quiz and is intended as a reference for instructors and self-study.
